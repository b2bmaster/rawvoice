RawVoice helps AI write in your voice through an optional taste interview, reusable voice files and editing guidance.

AI can still make mistakes. Review the output and verify factual claims before use or publication.

Inside this release:
- RawVoice_Claude_1.0.zip — the installable skill, including its source and MIT license.
- SETUP_GUIDE.txt — both platform routes, interview, review and reuse.
- RAWVOICE_PROJECT_GUIDE.txt — combined workflow reference for Project-based use.
- PROJECT_INSTRUCTIONS.txt — copy only the marked instruction block into your private Project.
- PRODUCT_DESCRIPTION.txt — release-page copy.
- LIMITATIONS.txt — what to expect and what to check.
- FICTIONAL_DEMO.txt — clearly labeled illustrative example.
- LAUNCH_POST.txt — prepared announcement for use when the download is available.
- RELEASE_NOTES.txt — version scope and observed testing.
- FEEDBACK.txt — a privacy-conscious feedback template.
- LICENSE — the existing MIT license, retained unchanged.

1.0 is the first public release, prepared from an internal development build. The writing guides, factual-integrity guide, interview playbook, profile template, cleaner and core writing/interview rules are unchanged. Project instructions now explicitly point prompt-based users to the combined guide. Handoff text and version labels were adjusted. No new full Claude interview was run after the release-preparation changes. The earlier internal development test found successful workflows and remaining factual errors; see RELEASE_NOTES.txt.
