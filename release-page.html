Get started in Claude

  1. Upload RawVoice_Claude_1.0.zip through Customize → Skills and enable rawvoice-write-and-edit-prose.
  2. Create a private Project and save the supplied Project instructions.
  3. Start Quick mode or import an existing profile. Review both generated files.
  4. Add VOICE_PROFILE.md and VOICE_CARD.md to Project knowledge. Test an ordinary writing request in a fresh chat.

What RawVoice does

RawVoice combines an optional interview, reusable voice preferences, format guidance and optional text cleanup. It supports drafting and editing posts, articles, emails and other prose when the skill and profile are available.

It is an instruction-based writing aid. Results depend on the model, your inputs and the active setup. A profile can misstate a preference, and a draft can add an unsupported detail. Read the limitations.
