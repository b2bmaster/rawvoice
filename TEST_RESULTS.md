# RawVoice 1.0 — Test scope

On 26 October 2026, the shipped ChatGPT Project guide and instructions were used in a private, Project-only-memory test with a clearly fictional persona. The selected model was GPT-6 with Medium effort.

## Observed in this run

- All 15 Quick questions completed, one at a time.
- Both profile files generated and downloaded. The detailed profile included 15 question-and-answer pairs; question 5 and 8 wording matched the observed questions.
- Reviewed qualifiers, format exceptions and the distinction between confirmed preferences and unknowns were preserved in the inspected profile/card rules.
- Both files were manually added to Project sources. A fresh chat retrieved five requested preference areas with their qualifications, citing the profile.
- Separate fresh chats produced an email and a fictional LinkedIn post from ordinary requests that did not name RawVoice. The email preserved the supplied Thursday/Friday dates. The post retained the three-article scope and did not invent measured improvements in time or errors.
- The first writing responses were evaluated without corrective follow-ups. Zero changes and zero review-only characters were found by the independent text cleaner on the downloaded profile/card and saved writing responses.

## Limits

This is one fictional-persona run and two writing examples, not a statistical evaluation or a promise of perfect accuracy, exact imitation or reliable routing for every prompt. Native skill activation is not claimed for ChatGPT: this route uses Project sources and instructions. An approval-only message followed the original profile handoff; no profile rewrite was requested.

One browser-control error sent a fictional interview answer to an older Claude test chat. That response was stopped and excluded from ChatGPT results; no profile changes were reported there. The ChatGPT interview continued in the correct test chat.

Earlier Claude testing and its known factual failures remain documented in RELEASE_NOTES.txt and LIMITATIONS.txt. This ChatGPT run does not erase those observations. The fictional profiles, interview answers and private chat links are not distributed with RawVoice.
